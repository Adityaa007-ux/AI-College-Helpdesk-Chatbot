# AI College Helpdesk Chatbot

## Project Overview

The AI College Helpdesk Chatbot is an intelligent conversational assistant designed to answer common student queries related to admissions, exams, fees, hostel, library, transport, Wi-Fi, and campus facilities.

The chatbot uses rule-based NLP logic and intent recognition to provide instant responses through a simple Streamlit web interface.

---

## Features

- AI-powered college helpdesk chatbot
- Answers student queries instantly
- Handles admission-related questions
- Provides exam and result information
- Gives fee and scholarship details
- Supports hostel and campus facility queries
- Simple and interactive web interface
- Chat-based user interaction

---

## Project Workflow

1. User enters a query
2. System analyzes keywords
3. Intent is identified
4. Appropriate response is generated
5. Response is displayed to the user
